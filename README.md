# AI-Builders-Conference

**Decoding the Hype** rates AI news stories for hype and for gaps in the evidence, so readers can see what a headline actually backs up. Built by Leyla for the Women AI Builders 5-Day Challenge (6 to 10 October 2026). Ratings by Claude.

Live site: https://hype-decoder-shell.lovable.app/

## What's in this repo

- `site/` is the code for the live website (a Lovable project using Supabase). It is a snapshot taken on 10 October 2026; Lovable keeps building from its own repository, so later changes to the live site may not appear here. The `.env` file is left out, so running it locally needs your own Supabase project URL and publishable key.
- `engine/` holds the rating rubric and scoring work behind the site.
- `master-project-brief.md`, `workstreams/`, `backlog/`, `prep/`, `news-research/`, `mockup/` and `archive/` are the planning notes and research from the challenge week.
