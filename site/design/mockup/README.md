# Design mockup (reference only)

Copied from the public repo `LeylaTurk/AI-Builders-Conference` (`mockup/project/`) on 6 Oct 2026. These files are the visual reference for the site, not app code: every story, publisher and score in them is fictional. Don't import or serve them.

- `Main.dc.html`: the feed page (cards, sort buttons, side panel with the rating legend).
- `Story.dc.html`: "Why this rating?" story page (scores, findings, breakdown, Behind the Claim).
- `Check.dc.html`: "Check an article" (paste text, private result).
- `HowRatings.dc.html`: "How ratings work" and Learn.

Colours and fonts: Night edition (header #2B1B5E with dot texture and torn edge, yellow highlighter #FFE34D, page #F6F3FF, links #5B3FD1), Fraunces for headlines, Public Sans for interface text. Chillies #EF4F27; Evidence gaps flags coloured by level (1 #1BAF7A, 2 #E6B400, 3 #F08A24, 4 #DB2E4B, 5 #8E0E2E).
